# Guide for myself and other (I hope)
Here you will find all sorts of example project to grasp a sense of what a math engineering can/should do: Data science, Data Mining, Time Series, Machine Learning, Metaheuristics, Risk analysis, etc.
I will be adding stuff over time, but the main idea is, for every area, explain broad concepts, then go into detail, and finally present one or two real life projects (ideally) to have both a base of how the theory works in practice and a base for the coding.
The code I will mostly base it on python, but I will try to learn and incorporate other languages (R, SQL, etc.).

And of course, all will be in English, so you can learn also technical vocabulary in this particular language
